    openid

    기본 신원 확인

  • 📧
    email

    profile

    프로필 정보 접근

허용을 클릭하면 개인정보 처리방침에 동의하게 됩니다.

OAuth2 동의 API

  • GET /oauth2/consent - 동의 화면 정보 조회
  • POST /oauth2/consent - 동의 처리

Query Parameters: client_id, scope, state, redirect_uri
