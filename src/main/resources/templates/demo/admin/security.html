IP 차단

보안 관리 API

  • GET /admin/security/blocked-ips - 차단된 IP 목록
  • POST /admin/security/blocked-ips - IP 차단
  • DELETE /admin/security/blocked-ips/{id} - IP 차단 해제 (id)
  • DELETE /admin/security/blocked-ips/ip/{ipAddress} - IP 차단 해제 (주소)
  • GET /admin/security/blocked-ips/check/{ipAddress} - 차단 여부 확인
  • GET /admin/security/accounts/status/{username} - 계정 잠금 상태
  • POST /admin/security/accounts/unlock - 계정 잠금 해제 (username 본문)
  • GET /admin/security/settings - 보안 설정 조회
