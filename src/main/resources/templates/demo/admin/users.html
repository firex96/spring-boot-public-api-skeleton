사용자 관리

사용자 그룹 할당과 권한 확인 — 사용자 목록 API 는 없으므로 사용자 ID 로 조회한다

그룹

사용자 ID 를 입력해 조회하세요.

권한

사용자 ID 를 입력해 조회하세요.

사용자 관리 API

  • GET /admin/users/{userId}/groups - 사용자 그룹 조회
  • GET /admin/users/{userId}/groups/detail - 배정 시각·만료가 든 그룹 매핑
  • POST /admin/users/{userId}/groups - 그룹 할당 (roleIds 목록)
  • PUT /admin/users/{userId}/groups - 그룹 목록을 통째로 교체
  • DELETE /admin/users/{userId}/groups/{groupId} - 그룹 제거
  • GET /admin/users/{userId}/permissions - 유효 권한 조회 (그룹 상속)
  • GET /admin/users/{userId}/permissions/{permissionCode}/check - 권한 보유 확인
