권한 관리 API

  • GET /admin/permissions - 전체 권한 조회
  • GET /admin/permissions/by-resource?resourceType={type} - 리소스 타입별 필터링
  • POST /admin/permissions - 권한 생성
  • PUT /admin/permissions/{id} - 권한 수정 (이름·설명만)
  • DELETE /admin/permissions/{id} - 권한 삭제
