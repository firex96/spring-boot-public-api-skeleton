그룹 관리 API

  • GET /admin/groups - 전체 그룹 조회
  • POST /admin/groups - 그룹 생성
  • PUT /admin/groups/{id} - 그룹 수정
  • DELETE /admin/groups/{id} - 그룹 삭제
  • GET /admin/groups/{id}/permissions - 그룹 권한 조회
  • POST /admin/groups/{id}/permissions - 그룹에 권한 추가 (permissionIds 목록)
  • PUT /admin/groups/{id}/permissions - 그룹 권한 목록을 통째로 교체
  • DELETE /admin/groups/{groupId}/permissions/{permissionId} - 그룹에서 권한 제거
