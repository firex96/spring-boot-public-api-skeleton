OAuth2 클라이언트 API

  • GET /admin/oauth2/clients - 클라이언트 목록
  • POST /admin/oauth2/clients - 클라이언트 등록
  • PUT /admin/oauth2/clients/{id} - 클라이언트 수정
  • DELETE /admin/oauth2/clients/{id} - 클라이언트 삭제
  • POST /admin/oauth2/clients/{id}/secret - 시크릿 재생성
  • POST /admin/oauth2/clients/{id}/deactivate - 비활성화 (재활성화 API 는 없다 — 새 클라이언트를 등록한다)
  • GET /admin/oauth2/clients/{id} - 클라이언트 상세
  • GET /admin/oauth2/clients/active - 활성 클라이언트만
