감사 로그 API

  • GET /admin/audit/logs - 로그 목록 조회 (페이지네이션)
  • GET /admin/audit/logs/search - 로그 검색
  • GET /admin/audit/logs/user/{userId} - 사용자별 로그
  • GET /admin/audit/event-types - 이벤트 타입 목록
  • GET /admin/audit/event-categories - 이벤트 분류 목록

검색 Query Parameters: userId, eventType, eventCategory, result, startDate·endDate(ISO DATE_TIME), page, size
